Evaluation Matrix

Core Test Modules

Executing under strict, DynamoDB-managed timed conditions, these modules gather precise data for comprehensive linguistic analysis.

1. MCQ & Fill Blanks

Foundational grammar and vocabulary assessment. Timers synchronized via WebSocket to ensure zero lag discrepancy.

2. Read Aloud

Students read displayed text. AI engine compares the audio trajectory against native baselines for pronunciation accuracy.

3. Repeat Audio

Tests listening comprehension and working memory. Prompt plays once; student must replicate the phrasing exactly.

4. Just-A-Minute (JAM)

Spontaneous speech evaluation on a given topic. Tracks hesitation, filler words, fluency, and overall prosody flow.

5. GenAI Essay Writing

Students construct essays based on a provided storyline. Evaluated instantly by integrated AWS Bedrock LLMs for context adherence, grammar, and structural integrity.

Platform Architecture

Technical Deep Dive

VOXYLET is engineered from the ground up as a fully managed, multitenant B2B SaaS platform. It eschews traditional monolithic designs for a highly distributed cloud-native architecture optimized for real-time audio processing and AI evaluation.

01. Node.js Backend

Powered by a robust single-instance Node.js backend handling all business logic, routing, and API integrations within a unified, high-performance execution environment.

02. AWS DynamoDB

Manages high-speed session tracking and strict exam timers, ensuring millisecond-synchronized state across all active test environments globally.

03. AWS S3 & SES

S3 acts as the secure repository for direct streaming of student recorded responses. AWS SES handles automated transactional emails to students and faculty.

04. AI Engines

Integration with Wav2Vec2 and BiLSTM networks for trajectory-based speech signal analysis. Generative modules powered by AWS Bedrock.
